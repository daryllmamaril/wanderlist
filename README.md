# Wanderlist - Your Trip Packing Assistant 🧳

Wanderlist is a simple, intuitive packing app designed to help you organize and track the items you need for your trips. Whether you're heading on a weekend getaway or a month-long adventure, Wanderlist ensures you don't forget a thing!

## Features ✨

- **Add Items:** Easily create a list of items you need to pack.
- **Sorting:** Sort your items by default, packed, or unpacked.
- **Mark All as Complete/Incomplete:** With one click, mark all items as packed or unpacked.
- **Reset List:** Quickly reset your list to its initial state.
- **Delete All Items:** Clear your list with a single action.
- **Track Progress:** See how many items you’ve packed out of the total number of items.

## Tech Stack 🛠️

- **React:** For building the user interface.
- **Zustand:** For state management, providing a simple and scalable solution to handle the app's state.

## Future Improvements 🚀

- User authentication to save packing lists for multiple trips.
- Custom categories for better item organization.
- Shareable packing lists with friends or family.
